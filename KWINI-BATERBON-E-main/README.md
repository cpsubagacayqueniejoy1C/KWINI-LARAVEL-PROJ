# Central Philippine State University (CPSU) - Student Bulletin Portal & Dashboard

A professional web-based institutional platform built for **Central Philippine State University (CPSU)**. This application transforms a default Laravel framework into a unified university portal featuring real-time announcements, category filters, search capabilities, and a secure student/staff authentication workflow.

---

## 🚀 Key Features

* **CPSU Announcement Bulletin Hub (`/`)**: Real-time university news, enrollment guidelines, examination schedules, and campus event feeds.
* **Smart Filtering & Search**: Instant keyword search and category filtering (*All, Enrollment, Academic, Events*) for quick access to announcements.
* **Institutional Branding**: Features the official CPSU seal and an emerald-and-slate color palette across all public and authenticated views.
* **Secure Authentication System**: Custom login and registration flow connected to a MySQL database (`KWINI`) with automatic redirection back to the announcement bulletin board upon login/registration.
* **Interactive Student Dashboard**: Personalized user greeting, enrollment status tracking, and quick navigation back to campus announcements.

---

## 🛠️ Tech Stack

* **Backend**: PHP, Laravel
* **Frontend**: React.js, Inertia.js, Tailwind CSS
* **Database**: MySQL (`KWINI` database)
* **Environment/Tools**: Composer, Node.js, Vite, Git & GitHub, VS Code / Termux
